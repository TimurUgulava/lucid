# Триггеры

Проверка в чистом контексте: модели даётся список установленных скиллов
и один запрос, фиксируется, какой скилл она выбрала.

## Должен сработать

1. «Объясни мне эту статью, я её три раза перечитал и не понял» + вложенный PDF.
2. «Хочу понять, как работает attention в трансформерах, сделай так, чтобы дошло».
3. «Вот отчёт по рынку, который ты только что собрал. Подай его понятно, чтобы я уловил главное за пять минут».
4. «Разжуй этот договор, что там важно» + ссылка.
5. «Сделай видео-объяснение про то, как устроен сложный процент».

## Не должен сработать

1. «Собери обучающий лендинг по промтингу для сотрудников, с заданиями и прогрессом» → обучающий материал для других.
2. «Сделай презентацию на 10 слайдов по этому отчёту» → слайды.
3. «Переведи эту статью на русский» → перевод.
4. «Кратко перескажи, о чём этот текст, в трёх предложениях» → пересказ текстом.
5. «Сверстай этот гайд в PDF» → вёрстка документа.
