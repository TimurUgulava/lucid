# Калибровка

Сюда падает опыт настоящих запусков. Когда человек заметно переделал
результат или попросил переделать целиком, пара сохраняется в
`unprocessed/` файлом `ГГГГ-ММ-ДД-<тема>.md`:

```markdown
# <тема>
Запрос: <как просили>
Выдал: <что было: ссылка на папку или суть в трёх строках>
Попросили: <что переделать и как>
Почему, своими словами человека: <если сказал>
```

Когда пар наберётся три-пять, они разбираются вместе: ищется общий
паттерн, а не частный случай, и превращается в правку `SKILL.md` или
справочника. Разобранные пары переносятся в `processed/`.

Пары — ваши рабочие материалы, git их не отслеживает: `unprocessed/` в `.gitignore`.
