# solarpunk

Тёплая органика: будущее, экология, обнадёживающий тон. Образцы жанра:
solarpunk-иллюстрация, ретрофутуризм, смесь органики и геометрии.

```html
<link href="https://fonts.googleapis.com/css2?family=Rubik:wght@400;600;800&family=Literata:ital,opsz,wght@0,7..72,400;0,7..72,600;1,7..72,400&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">
```

```css
:root {
  --bg: #f5f0e1; --bg-2: #ebe3cb; --bg-3: #e2d8ba;
  --ink: #2a2418; --ink-dim: #5a4f3a; --muted: #6b6049;
  --accent: #3f6a31; --accent-2: #e6a23c;
  --ok: #4a7c3a; --warn: #b87420; --err: #c9633a;
  --rule: #d4c8a8;
  --display: 'Rubik', sans-serif;
  --body: 'Literata', Georgia, serif;
  --mono: 'JetBrains Mono', monospace;
  --radius: 14px; --rule-w: 1px;
}
```

Типографика: заголовок страницы 56–110 px Rubik 800, заголовок блока
36–60 px Rubik 600, подпись 18 px Literata / 1.65.

Да: пара акцентов лист и солнце вместе, щедрые скругления, мягкие
органические формы на фоне с низкой прозрачностью. Нет: холодные синие,
неон, острые углы, чистые чёрный и белый.

## Видео

Шкала Full HD: титул 116 px Rubik 800, заголовок 84 px 600, подписи
38 px Literata, пояснения 30 px, служебный 26 px JetBrains Mono. Проявление
500 мс с подъёмом 14 px, пауза подписи 520 мс. Линии 5 px, карточки со
скруглением 14 px, пара акцентов лист и солнце. Декор: мягкие органические
плоскости на фоне с `data-decor`, под текст всегда ровная поверхность.

Переменные для `:root` сцены, поверх блока токенов:

```css
:root {
  --t-title: 116px; --t-h: 84px; --t-copy: 38px; --t-note: 30px; --t-meta: 26px; --display-weight: 800;
  --fade: 500ms; --fade-rise: 14px; --caption-pause: 520ms; --stroke: 5px;
}
```

Акцент текстом на фоне: `--accent` даёт 5.6:1 на `--bg`, им можно писать слова заголовка и метки; `--accent-2` для плоскостей, обводок и состояний, не для текста на фоне.

Все три гарнитуры содержат кириллицу и латиницу; гарнитура без письма языка объяснения молча подменяется браузером, и проверка шрифтов это ловит.
