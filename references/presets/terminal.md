# terminal

Экран терминала как метафора: код, системы, устройство ИИ. Берётся, когда
тема про это; иначе читается как декорация. Образцы жанра: интерфейсы в
Blade Runner 2049 и Severance, фосфорные мониторы.

```html
<link href="https://fonts.googleapis.com/css2?family=Ubuntu+Mono:wght@400;700&family=IBM+Plex+Sans:wght@400;500;600&family=JetBrains+Mono:wght@400;500;700&display=swap" rel="stylesheet">
```

```css
:root {
  --bg: #0a0e0a; --bg-2: #14181a; --bg-3: #1a201c;
  --ink: #c0d8b8; --ink-dim: #8fa88a; --muted: #7d9a77;
  --accent: #58ff3a; --accent-2: #ffb84a;
  --ok: #58ff3a; --warn: #ffb84a; --err: #ff4a4a;
  --rule: #1f2a1a;
  --display: 'Ubuntu Mono', monospace;
  --body: 'IBM Plex Sans', sans-serif;
  --mono: 'JetBrains Mono', monospace;
  --radius: 0; --rule-w: 1px;
}
```

Типографика: заголовок страницы 48–80 px Ubuntu Mono 700, заголовок блока
32–48 px Ubuntu Mono 700, подпись 17 px IBM Plex Sans: моноширинный в длинных
подписях утомляет, он остаётся для заголовков, меток, чисел и кода.

Да: строчная развёртка через `body::after`, мигающий курсор в шапке, лёгкое
свечение текста `text-shadow: 0 0 8px var(--accent)` на заголовках, символы
псевдографики в разделителях. Нет: свечение на всём, розовый как основной
акцент, Ubuntu Mono в подписях.

## Видео

Шкала Full HD: титул 110 px Ubuntu Mono 700, заголовок 80 px Ubuntu Mono 700,
подписи 36 px IBM Plex Sans, пояснения 30 px, служебный 26 px JetBrains
Mono. Проявление 120 мс без подъёма, пауза подписи 360 мс; появление
объектов как печать слева направо допустимо, но текст после появления
неподвижен. Линии 3 px, псевдографика в разделителях, пиксельного шрифта с кириллицей на Google Fonts нет, кроме Press Start 2P, он для заголовков слишком широк; карточки с рамкой
1 px без радиуса. Свечение только на заголовке; строчная развёртка —
отдельный элемент поверх кадра с `data-decor` и `pointer-events: none`, не
псевдоэлемент. У заголовков `--display-weight: 700`, акцент в заголовке
прямым начертанием цвета акцента (`h1 em { font-style: normal }`), вместо
полоски у надзаголовка — псевдографика. Длинные подписи никогда пиксельным
шрифтом.

Переменные для `:root` сцены, поверх блока токенов:

```css
:root {
  --t-title: 110px; --t-h: 80px; --t-copy: 36px; --t-note: 30px; --t-meta: 26px; --display-weight: 700;
  --fade: 120ms; --fade-rise: 0px; --caption-pause: 360ms; --stroke: 3px;
}
```

Акцент текстом на фоне: `--accent` даёт 14.6:1 на `--bg`, им можно писать слова заголовка и метки; `--accent-2` для плоскостей, обводок и состояний, не для текста на фоне.

Все три гарнитуры содержат кириллицу и латиницу; гарнитура без письма языка объяснения молча подменяется браузером, и проверка шрифтов это ловит.
