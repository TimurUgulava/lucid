# brutalist

Сырой, тяжёлый, намеренно неудобный. Авторский голос, контркультура.
Образцы жанра: обложки Bloomberg Businessweek, сайты на голом HTML.
Требует руки: без неё получается «тёмный шаблон с кислотной кнопкой».

```html
<link href="https://fonts.googleapis.com/css2?family=Oswald:wght@500;700&family=PT+Serif:ital,wght@0,400;0,700;1,400&family=Ubuntu+Mono:wght@400;700&display=swap" rel="stylesheet">
```

```css
:root {
  --bg: #f4f1e8; --bg-2: #ffffff; --bg-3: #e9e4d6;
  --ink: #0a0a0a; --ink-dim: #222222; --muted: #555555;
  --accent: #c0392b; --accent-2: #d4ff00;
  --ok: #0a0a0a; --warn: #e53e3e; --err: #e53e3e;
  --rule: #0a0a0a;
  --display: 'Oswald', Impact, sans-serif;
  --body: 'PT Serif', Georgia, serif;
  --mono: 'Ubuntu Mono', monospace;
  --radius: 0; --rule-w: 3px;
}
```

Типографика: заголовок страницы 80–160 px Oswald 700 капителью, узкая
гарнитура держит длинные русские заголовки, заголовок блока 44–72 px капителью,
подпись 17 px PT Serif, метки Ubuntu Mono капителью.

Да: чёрные рамки 2–4 px, асимметрия, видимая сетка, конфликт красного и
кислотного, резкие переходы 50 мс или без них. Нет: тени, скругления,
плавные анимации, градиенты, вылизанные элементы форм.

## Видео

Шкала Full HD: титул 140 px Oswald 700 капителью, заголовок 96 px,
подписи 36 px PT Serif, пояснения 30 px, служебный 26 px Ubuntu Mono.
Проявление 0 мс, резкое появление без подъёма, пауза подписи 360 мс. Линии
6 px чёрные, рамки 3–4 px, карточки без радиуса, асимметрия и видимая
сетка. Неудобство только в композиции: подписи и схемы читаются по общим
порогам размера и контраста, кислотный цвет только на одном объекте.

Переменные для `:root` сцены, поверх блока токенов:

```css
:root {
  --t-title: 140px; --t-h: 96px; --t-copy: 36px; --t-note: 30px; --t-meta: 26px; --display-weight: 700;
  --fade: 0ms; --fade-rise: 0px; --caption-pause: 360ms; --stroke: 6px;
}
```

Акцент текстом на фоне: `--accent` даёт 4.8:1 на `--bg`, им можно писать слова заголовка и метки; `--accent-2` для плоскостей, обводок и состояний, не для текста на фоне.

Все три гарнитуры содержат кириллицу и латиницу; гарнитура без письма языка объяснения молча подменяется браузером, и проверка шрифтов это ловит.

Видимая сетка в кадре — отдельная плоскость с `data-decor` (SVG-линии или CSS-градиент), под текстом всегда ровная поверхность; плоскость титула без скругления, радиус поля в каркасе берётся из `--radius`.
