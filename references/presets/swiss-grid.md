# swiss-grid

Международный типографический стиль: технический материал, документация,
спецификации. Образцы жанра: Müller-Brockmann, Vignelli, швейцарские плакаты.

```html
<link href="https://fonts.googleapis.com/css2?family=Inter+Tight:wght@300;400;500;600;700;800&family=JetBrains+Mono:wght@400;500;700&display=swap" rel="stylesheet">
```

```css
:root {
  --bg: #ffffff; --bg-2: #f5f5f5; --bg-3: #ececec;
  --ink: #0a0a0a; --ink-dim: #3a3a3a; --muted: #6e6e6e;
  --accent: #c62828; --accent-2: #d33;
  --ok: #2e7d32; --warn: #c77c00; --err: #d33;
  --rule: #0a0a0a;
  --display: 'Inter Tight', Helvetica, Arial, sans-serif;
  --body: 'Inter Tight', Helvetica, Arial, sans-serif;
  --mono: 'JetBrains Mono', monospace;
  --radius: 0; --rule-w: 2px;
}
```

Типографика: заголовок страницы 64–120 px вес 800, заголовок блока 34–52 px
вес 700, подпись 17–18 px вес 400 / 1.55, метки 13 px вес 500 капителью.
Контраст весов 300 против 800, табличные цифры.

Да: сетка 12 колонок с интервалом 24 px, всё по левому краю, чёрные линии
1–2 px, один красный акцент, много воздуха. Нет: серые тонкие рамки, тени,
скругления, центрированные заголовки, курсив в подписях.

## Видео

Шкала Full HD: титул 128 px Inter Tight 800, заголовок 88 px 700, подписи
36 px 500, пояснения 30 px, служебный 24 px. Проявление 200 мс без подъёма,
пауза подписи 320 мс. Линии 2 px чёрные, стрелки без скруглений, карточки
без заливки и без радиуса, сетка 12 колонок на кадр: объекты к колонкам.
Декор отсутствует; красный только на одном объекте в кадре.

Переменные для `:root` сцены, поверх блока токенов:

```css
:root {
  --t-title: 128px; --t-h: 88px; --t-copy: 36px; --t-note: 30px; --t-meta: 24px; --display-weight: 800;
  --fade: 200ms; --fade-rise: 0px; --caption-pause: 320ms; --stroke: 2px;
}
```

Акцент текстом на фоне: `--accent` даёт 5.6:1 на `--bg`, им можно писать слова заголовка и метки; `--accent-2` для плоскостей, обводок и состояний, не для текста на фоне.

Все три гарнитуры содержат кириллицу и латиницу; гарнитура без письма языка объяснения молча подменяется браузером, и проверка шрифтов это ловит.
