# Сборка видео

Видео — те же блоки, что и страница, проигранные во времени под озвучку:
отдельный титульник, сцена на блок, финал. Конвейер: режиссёрская карта →
сцены в HTML → озвучка → пробные экраны и проверка → остальные сцены →
покадровая запись → склейка → проверка экспорта. Всё локально, кроме вызова
Gemini TTS. Стандарт качества и рубрика ревью — `visual-quality.md`.

Формат по умолчанию 1920×1080, 24 кадра в секунду. Уменьшенный черновик
(`--fast`) не выдаётся как финал. Озвучка — настройка отдельная от стиля:
«покажи первые экраны без озвучки» относится к пробам, полное видео,
заказанное с голосом, выходит с голосом.

Требования: Python 3.9+, `playwright` с Chromium, `ffmpeg`:

```
pip3 install playwright && python3 -m playwright install chromium
brew install ffmpeg          # macOS; на Linux — пакетный менеджер
```

## Файлы в рабочей папке

```
scenes/
  scenes.json        порядок сцен, нарратив, размер кадра
  00-title.html      титульник
  01-<форма>.html    по сцене на блок
  …
  99-end.html        финал: «одной фразой»
  scene-checks.json  отчёт проверки сцен
audio/
  <id>.wav           озвучка сцены
  durations.json     длительность каждой сцены в секундах
.render/             сегменты, кадры, отчёты рендера
video.mp4
```

Схема `scenes.json`:

```json
{
  "size": "1920x1080", "fps": 24, "design": "1920x1080",
  "scenes": [
    {"id": "00-title", "file": "00-title.html", "narration": "…"},
    {"id": "01-causal", "file": "01-causal.html", "narration": "…"}
  ]
}
```

`design` — размер, под который свёрстаны сцены; при другом `size` рендер
масштабирует их целиком.

## Порядок

1. **Режиссёрская карта** — строка `Режиссура:` у каждого блока в
   `script.md`, состав строки и список композиций в `visual-quality.md`,
   раздел «Порядок работы перед сборкой». Титульник: заголовок, обещание и
   один образ по теме.
2. **Заготовки сцен** из `script.md`:
   ```
   python3 ${CLAUDE_SKILL_DIR}/scripts/scenes_from_script.py --script script.md --out-dir scenes --skeleton ${CLAUDE_SKILL_DIR}/assets/scene-skeleton.html
   ```
   Титульник собирается из `assets/scene-title.html`, остальные из
   `assets/scene-skeleton.html`: шапка, подпись, раскладка по форме,
   площадка пустая, данные формы и режиссура в комментарии. Переменные
   пресета профиля вставляются в `:root` каждой сцены, вместе с разделом
   «Видео» пресета, если он сдвигает шкалу или движение.
3. **Озвучка** до таймингов: сцена длится столько, сколько звучит её текст.
   ```
   python3 ${CLAUDE_SKILL_DIR}/scripts/tts.py scenes --scenes scenes/scenes.json --out-dir audio --voice <из профиля> --model <из профиля>
   ```
4. **Пробные экраны**: титульник, один содержательный, самый плотный.
   Нарисовать формы, прогнать проверку с кадрами, посмотреть кадры в
   полном размере и в 960 px, исправить, затем распространить систему на
   остальные сцены.
   ```
   python3 ${CLAUDE_SKILL_DIR}/scripts/check_scenes.py --scenes scenes/scenes.json --audio-dir audio --shots .shots --only 00-title,01-causal,04-compare
   ```
5. **Все сцены**: та же проверка без `--only`, ревью по рубрике из
   `visual-quality.md`, фактчек структуры схем.
6. **Рендер и экспорт**: рендер сам гоняет проверку сцен до записи и
   проверку экспорта после склейки; при дефектах останавливается.
   ```
   python3 ${CLAUDE_SKILL_DIR}/scripts/render_video.py --scenes scenes/scenes.json --audio-dir audio --out video.mp4
   ```

Переозвучить одну сцену: `tts.py scenes … --only 01-causal`. Перерисовать
одну: `render_video.py … --only 01-causal`, склейка идёт из всех сегментов.
Флаг `--style` у `tts.py` добавляет инструкцию манеры чтения; не проверено,
читает ли модель её вслух, по умолчанию выключен.

## Сцена

Каркас свёрстан под 1920×1080 в координатах кадра: зоны `meta`, `h1`,
`stage`, `caption`, `source`, `folio`; раскладки `layout-wide`,
`layout-split`, `layout-tall`, у титульника `layout-cover`. Шкала размеров
и движение заданы переменными каркаса, их имена и ориентиры — в
`visual-quality.md`, раздел «Шкала типографики»; пресет меняет их в разделе
«Видео». Текст на сцене: заголовок-утверждение, подписи к форме и
внешняя подпись; нарратив на экран не выводится, субтитры не нужны.

Чем управляется время:

| Приём | Разметка | Что происходит |
|---|---|---|
| Появление по слову нарратива | `data-at-word="15"` | объект появляется, когда прозвучало 15 слов; рендер пересчитывает по длине озвучки |
| Появление по времени | `data-at="2.5"` | с 2,5 с объект проявляется за `--fade` |
| Подпись после объектов | `data-after="id1,id2"` или `data-after="@stage"` | подпись ждёт полной видимости объектов плюс `--caption-pause`; с `data-at-word` берётся позднее из двух |
| Затухание | `data-off="7"` | с 7 с объект гаснет до 18 процентов |
| Счётчик | `data-count-to="340" data-at="3" data-dur="2"` | число растёт от 0 до 340 за 2 с |
| Дорисовка линии | класс `draw` на `path` с `data-at` | штрих тянется CSS-анимацией, рендер её перематывает |
| Декор | `data-decor` на фоновой плоскости | проверка не считает её перекрытием |
| Текст на линии намеренно | `data-on-line` на тексте, `data-under` на линии | проверка пропускает это пересечение |
| Узел ветвления | `data-junction="имя"` на группе линий или на каждой из них | линии одного узла могут сходиться, остальные пересечения линий — дефект |

Внешняя подпись помечается `data-role="caption"`: без `data-after` она
считается ошибкой; какие ещё ошибки зависимостей останавливают сборку,
сказано в `visual-quality.md`, раздел «Подписи и движение». Объект внутри
группы с `data-at` появляется не раньше группы. Подпись внутри объекта
лежит в его группе и появляется с ним.

Площадка рисуется теми же формами, что для страницы (`visual-forms.md`), в
размерах кадра: подписи на схеме не меньше `--t-note`, числа и метки не
меньше `--t-meta`. Один доминирующий объект, площадка заполнена.

## Проверка

`check_scenes.py` — что именно проверяется, в `visual-quality.md`. Отчёт
`scene-checks.json` называет сцену, время, элемент и причину; список
«нужен осмотр» закрывается только глазами. `ffprobe video.mp4` показывает
длительность, равную сумме сцен; первая и последняя сцены смотрятся в
плеере: звук есть, детали появляются по ходу речи.
